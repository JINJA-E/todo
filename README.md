# Todo

HTML, CSS, JavaScript만으로 만든 할 일 관리 앱입니다. 빌드나 설치 과정이 필요 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

```bash
open index.html
```

## 기능

- 할 일 추가, 완료 표시, 삭제
- 제목을 더블클릭해서 수정 (Enter 저장, Esc 취소, 내용을 비우면 삭제)
- 전체 / 진행 중 / 완료 필터
- 완료 항목 한 번에 삭제
- 브라우저 `localStorage`에 자동 저장 (새로고침해도 유지)
- 다크 모드 자동 지원

## 파일 구조

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
