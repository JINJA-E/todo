# Todo

HTML, CSS, JavaScript만으로 만든 할 일 관리 앱입니다. 빌드나 설치 과정이 필요 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

```bash
open index.html
```

VS Code에서는 Live Preview 확장으로 `index.html`을 열면 편집하면서 바로 확인할 수 있습니다.

## 기능

- 할 일 추가, 완료 표시, 삭제
- 제목을 더블클릭해서 수정 (Enter 저장, Esc 취소, 내용을 비우면 삭제)
- **카테고리** (개인 / 업무 / 공부 / 장보기)와 카테고리 필터
- **마감일**: 오늘까지, 내일까지, N일 남음, N일 지남으로 표시하고, 칩을 눌러 바꿀 수 있음
- **중요 표시(⭐)**: 중요한 항목은 항상 위에 모임
- **순서 바꾸기**: ⠿ 손잡이를 끌거나, 손잡이에 포커스한 뒤 ↑/↓ 키
- 전체 / 진행 중 / 완료 필터, 완료 항목 한 번에 삭제
- **진행률 막대**와 모두 완료했을 때 축하 효과
- 오늘 날짜 표시, 목록 제목 바꾸기, 테마 색상 5가지
- 브라우저 `localStorage`에 자동 저장, 다크 모드 자동 지원

## 파일 구조

| 파일 | 설명 |
